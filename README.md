# CSharp Practice Tasks 1.2

Учебный консольный проект на **C#**, содержащий 4 задания по работе с циклами, пользовательским вводом и арифметическими операциями.

## О проекте

После запуска программа предлагает выбрать одно из четырёх заданий. Выбранное задание выполняется в консоли.

Исходный код находится в файле `Program.cs`.

## Задания

### 1. Расчёт вклада с помощью `for`

Пользователь вводит первоначальную сумму вклада и количество месяцев.

Для каждого месяца к вкладу добавляется **7%** от текущей суммы. Расчёт выполняется с помощью цикла `for`.

В конце программа выводит итоговую сумму вклада.

### 2. Расчёт вклада с помощью `while`

Задание аналогично первому, но для выполнения ежемесячного расчёта используется цикл `while`.

- Процент: **7%**
- Пользователь вводит сумму вклада.
- Пользователь вводит количество месяцев.
- Цикл выполняется указанное количество раз.

### 3. Таблица умножения

С помощью вложенных циклов `for` программа выводит таблицу умножения для чисел от **1 до 9**.

Используются два цикла:

- внешний — перебирает числа от 1 до 9;
- внутренний — также перебирает числа от 1 до 9.

### 4. Умножение двух чисел

Пользователь вводит два числа.

Каждое число должно находиться в диапазоне **от 0 до 10**.

После успешного ввода программа выводит результат их умножения.

Если введено число вне диапазона или некорректное значение, программа сообщает об ошибке и предлагает повторить ввод.
